# Memoria del proyecto

Lo que vamos aprendiendo al hacer vídeos, para no repetir errores y para que cualquier sesión nueva de Claude (aquí o en el Mac) arranque con el contexto.

| Archivo | Qué guarda |
|---|---|
| `learnings.md` | Trucos, fallos y soluciones técnicas, con fecha. Lo más reciente arriba. |
| `preferences.md` | Gustos y criterios de Santi: estilo, tono, formato, qué sí y qué no. |
| `backlog.md` | Próximos pasos e ideas para probar. |

## Reglas para Claude

- **Al empezar una sesión:** lee los tres archivos antes de proponer nada.
- **Durante el trabajo:** cuando algo falle y lo resuelvas, o descubras un truco, añádelo a `learnings.md` en el momento, sin esperar al final.
- **Cuando Santi corrija o elija algo** (estilo, tono, herramienta), anótalo en `preferences.md`.
- **Al cerrar la sesión:** actualiza `backlog.md` (tacha lo hecho, añade lo nuevo).
- Formato de entrada: `- AAAA-MM-DD · [tema] lo aprendido. Cómo aplicarlo.` Una o dos líneas, sin relleno.
- Si un aprendizaje cambia cómo se usa una herramienta, actualiza también `docs/` o la skill del plugin correspondiente.

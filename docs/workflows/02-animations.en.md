# Workflow 2 — Animations and effects over your explanation

*[Español](02-animations.md)*

Tools: video-use + HyperFrames or Remotion.

## Idea

Because video-use has a transcript with word-level timestamps, it can place overlays exactly when you say something. Example (in Spanish):

> "Cuando digo 'base de datos vectorial', pon encima un diagrama animado de embeddings entrando en la base de datos." ("When I say 'vector database,' put an animated diagram of embeddings entering the database on screen.")

Each animation is generated by a subagent in parallel with HyperFrames, Remotion, Manim, or PIL, then composited over the video.

## Steps

1. First make a clean cut (workflow 1).
2. Request animations by specifying the phrase or moment and what should be shown.
3. Review the render; iterate ("slower", "brand colors", "don't cover the face").
4. Save the animation code in `videos/<folder>/animations/` so it can be reused in other videos.

## Tips

- Define a brand palette and typeface once and save them in `docs/style/identity.md` so all animations are consistent.
- Diagram-style animations (flows, boxes, arrows) work best in HyperFrames (HTML/CSS); highly programmatic ones work best in Remotion.
- Before building an effect, a chart or a transition, look for it in the HyperFrames catalog (about 450 items): `npx hyperframes catalog <words>` and `npx hyperframes add <name>`. For data there are `data-chart`, `chart-story`, `mk-line-graph`, `count-up` and `spain-map`; for code, the ones in the tutorials section of the `faceless-video` skill. What you install is your own code: adapt it to the identity (see `docs/style/tokens.css`) and check it with `snapshot` before accepting it.

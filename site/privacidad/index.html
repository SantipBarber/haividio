La web

haividio.dev es una página estática. No usa cookies, analítica ni formularios, y no guarda datos de quien la visita. Cloudflare, que la sirve, puede registrar datos técnicos de las peticiones (como la dirección IP) para seguridad y funcionamiento, según su política de privacidad.

Haividio uploader

Haividio uploader es la autorización OAuth que usa el mantenedor de Haividio para subir sus propios vídeos a su propio canal de YouTube con la API de datos de YouTube (YouTube API Services). No es un servicio abierto a otras personas.

  • Qué datos usa: el permiso para subir vídeos, miniaturas y subtítulos al canal autorizado y para leer el resultado de la subida.
  • Dónde se guardan: las credenciales y el token se quedan en el ordenador del mantenedor, fuera del repositorio. No se envían a ningún servidor propio ni se comparten con terceros.
  • Cómo se revoca: desde la cuenta de Google, en Conexiones con terceros.

Al usar YouTube se aplican las Condiciones del Servicio de YouTube y la Política de Privacidad de Google.
